# 🗃️ ORM CRUD Project

This project is a **Python-based ORM CRUD system** that allows users to perform **Create, Read, Update, and Delete (CRUD)** operations on goods stored in a SQLite database.

---

## ✨ Key Features

* **Create Goods:** Add new items to the database.
* **Read Goods:** View existing goods.
* **Update Goods:** Modify details of existing goods.
* **Delete Goods:** Remove goods from the database.
* **Database Handling:** Uses SQLite (`goods.db`) for persistent storage.
* **Modular Code:** Organized with `crud.py` for operations and `database.py` for DB connection.

---

## 🔹 Project Structure

```
ORM_CRUD/
├── crud.py         # Create, Read, Update, Delete functions
├── database.py     # SQLite database connection
├── main.py         # Main script to run the program
├── goods.db        # SQLite database file
└── README.md
```

---

## 🛠 Tech Stack

* **Python 3.10+**
* **SQLite** (local database)
* **Git / GitHub**

---

## 👤 User Flow

1. Run `main.py` to start the program.
2. Use functions from `crud.py` to add, view, update, or delete goods.
3. All operations are performed on `goods.db` SQLite database.
4. Modular structure allows easy extension and maintenance.
